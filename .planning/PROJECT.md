# May VPN — проект

Десктопный VPN-клиент (macOS) в стилистике May Attacker: котик May May из сканлайнов,
пиксельный шрифт, Plex Mono, чёрные «чернила» — но на молочном фоне. Основной протокол — WireGuard.
Никаких логов, никакой БД: приложение живёт «от подключения до подключения», на диске только
зашифрованный ключ подключения к нашему VPS.

## Grill Me — вопросы и решения

**Q: Что делаем на VPS?** Только клиент. Ключ — готовый `.conf` (WireGuard / AmneziaWG) или ссылка
(`vless://`, `ss://`, `trojan://`, `hysteria2://`) с нашего VPS. Импорт: вставить текст или выбрать файл.

**Q: «Все популярные протоколы» — какие?** WireGuard (свой движок на `wireguard-go`, главный),
AmneziaWG (`amneziawg-go`, WG с обфускацией против DPI), VLESS (+Reality), Shadowsocks, Trojan,
Hysteria2 — через встроенное ядро `sing-box` как Go-библиотеку. OpenVPN/IKEv2 не делаем (внешние бинарники).

**Q: Как получить root для туннеля?** Системный хелпер: `mayvpnd install` (пароль macOS один раз)
кладёт бинарник в `/Library/PrivilegedHelperTools` и plist в `/Library/LaunchDaemons`. Это единственный
«след» в системе — и он удаляется кнопкой «Remove helper» / «Erase everything».

**Q: Сколько серверов?** Один VPS. Регион — подпись, которую пользователь задаёт при импорте
(никаких geo-IP запросов наружу).

**Q: Что значит «не логирует и не оставляет следов»?**
- Демон ничего не пишет: stdout/stderr → `/dev/null`, логгер wireguard-go — Silent, sing-box `log.disabled`.
  Ошибки уходят только клиенту по сокету.
- Нет БД. Состояние сессии, статистика, исходные DNS — только в памяти демона, теряются при отключении.
- `PostUp/PreUp/PostDown` из `.conf` игнорируются (это был бы запуск команд от root).
- Electron: `userData`, кэш, crash dumps — во временной папке, удаляется при выходе; сессия браузера in-memory.
- На диске один файл `~/Library/Application Support/May VPN/vault` — шифруется ключом из Keychain (`safeStorage`).
  В нём ключи подключения и 3 настройки (регион, kill switch, LAN). Рендерер ключей не видит.

**Q: Утечки?** Kill switch (по умолчанию ВКЛ): pf-якорь `com.apple/250.MayVPN` — пропускает только
lo0, наш utun, UDP/TCP к VPS и DHCP; LAN — опцией. DNS: оверрайд DNS primary-сервиса в динамическом
store `scutil` (живёт в памяти, исчезает при перезагрузке), восстанавливается при отключении.
IPv6: если у туннеля нет v6 — `::/1` и `8000::/1` в blackhole. При старте демон чистит хвосты (якорь pf).

**Q: Связь UI ↔ демон?** Unix-сокет `/var/run/com.maymay.vpn.sock`, `0600`, владелец — установивший
пользователь + проверка `LOCAL_PEERCRED`. Протокол — JSON lines: запросы `hello/connect/disconnect/status`,
события `state/stats`. Туннель живёт в демоне; выход из приложения = отключение.

**Q: Что показывает дашборд?** Регион (из vault), пинг (RTT TCP-рукопожатия к 1.1.1.1:443 *через туннель*,
каждые 3 с), скорость (↓/↑ по счётчикам интерфейса/WG, 1 с), время сессии. «Подключено» = первый
успешный пробник через туннель, а не просто поднятый интерфейс.

**Q: Как разрабатывать без root и VPS?** Демо-режим (`--demo`) — фейковый демон в main-процессе для UI.
Go-тесты: парсинг, UAPI, петля WireGuard↔WireGuard и AWG↔AWG в userspace (netstack, без root),
сборка конфигов sing-box через его же парсер, сокет-сервер с фейковым движком.

## UI (дизайн-пространство 480×800, масштаб под окно)
- **Загрузка:** котик бежит (рысь), за ним остаются следы лапок из сканлайнов и тают.
- **Сверху** — большой котик со щитом (лапка-эмблема) и мечом:
  - выкл — стоит, дышит, иногда поднимает меч, разглядывает и крутит его;
  - подключение — машет мечом и закрывается щитом (пока нет первого ответа через туннель);
  - подключились — отбрасывает щит и меч (летят по дугам, крутясь), сворачивается в клубок;
  - подключено — клубок крутится как глобус, иногда виляет хвостом; поле линий течёт.
  - отключение — разворачивается, ловит падающие сверху меч и щит.
- **Середина** — круглая кнопка-лапка (пиксельный круг, рамка 3px), статус и чип протокола.
- **Внизу** — статистика: регион, пинг, скорость, время сессии.
- Палитра: фон молочный `#F2EBDD`, «бумага» `#F8F3E8`, чернила `#0B0906`; шерсть кремовая.
  Не перенасыщать: без бабла, поле линий тише, чем у агента.
