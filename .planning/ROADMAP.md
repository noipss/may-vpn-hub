# Roadmap (GSD)

Каждая фаза: цель → задачи → проверка (verify) → атомарный коммит. Следующая фаза — только после verify.

| # | Фаза | Verify |
|---|------|--------|
| 0 | Разделить репо: агент → `may-attacker/`, создать `may-vpn/` | `npm test` агента зелёный из новой папки |
| 1 | Демон: профили (WG/AWG `.conf`, vless/ss/trojan/hy2 ссылки), `mayvpnd parse` | `go test ./internal/profile` |
| 2 | Движки: WireGuard, AmneziaWG (UAPI), sing-box (опции) | петли WG↔WG, AWG↔AWG через netstack; `box.New` для каждой ссылки |
| 3 | macOS: адреса/маршруты, DNS (scutil), kill switch (pf), сессия, сокет, install/uninstall | тест сервера с фейковым движком; генерация pf-правил и plist; `go vet` |
| 4 | Electron-оболочка: temp userData, vault (safeStorage), клиент хелпера, демо-режим, IPC | `npm test` (vault + протокол против `mayvpnd serve` в тест-режиме) |
| 5 | UI: молочная палитра, шапка «MAY VPN», кнопка-лапка, статистика, протокол, настройки | снимки экрана в демо-режиме |
| 6 | Котик: меч/щит SDF, позы (стоит/крутит меч, бой, бросок, клубок-глобус, ловит), загрузка с бегом и следами | покадровые снимки каждого состояния, 60 fps |
| 7 | Полировка, README, итоговая сверка | все тесты, снимки, чеклист без следов |
